# NOVA MEDIA 🎧📱

**NOVA MEDIA** is an advanced media application designed for seamless playback and management of songs, videos, and playlists, featuring a modern UI inspired by **Dark Glass & Neon** aesthetics.

---

## 🚀 Core Features
* **Media Playback:** Integrated player for high-quality audio and video content.
* **Playlist Management:** Easily organize, sort, and manage your media collections.
* **Modern UI/UX:** Sleek dark mode design with refined visual elements and a comfortable user experience.
* **High Performance:** Built with **Flutter** for fast and efficient execution on mobile devices.

---

## 🛠️ Tech Stack
* **Framework:** [Flutter](https://flutter.dev/) (Dart)
* **UI Design:** Custom Dark Glass & Neon Theme
* **Icons & Assets:** Optimized High-Resolution App Icons (`flutter_launcher_icons`)
